# Ai-policy-summarizer
AI-powered application that converts government policy PDFs into citizen-friendly summaries with keyword and entity extraction.
## Features

- Upload government policy PDFs
- Generate citizen-friendly summaries
- Extract important keywords
- Identify ministries, dates, and monetary values
- Store processed summaries
- Search previous policy summaries
## Learning Goals

- Backend Development with FastAPI
- AI Integration using Gemini
- PDF Processing
- Database Design
- React Frontend Development
- Git & GitHub Workflow
